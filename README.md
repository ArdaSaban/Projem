# Gezi Blogum

## Proje Hakkında

Gezi Blogum, Türkiye'nin farklı şehirlerini, tarihi yapılarını ve doğal güzelliklerini tanıtmak amacıyla hazırlanmış bir gezi blogu web sitesidir.

Bu proje HTML, CSS ve JavaScript kullanılarak geliştirilmiştir.

Web sitesinde kullanıcılar Türkiye'deki farklı şehirler hakkında bilgi edinebilir, şehir fotoğraflarını inceleyebilir ve arama kutusunu kullanarak istedikleri şehri bulabilir.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript

## Proje Özellikleri

- Ana sayfa ve tanıtım bölümü.
- Türkiye'den 12 farklı şehrin tanıtıldığı içerik sayfası.
- Şehirlere ait fotoğraflar.
- JavaScript ile çalışan arama ve filtreleme sistemi.
- Hakkımızda sayfası.
- Bilgisayar, tablet ve telefonlara uyumlu tasarım.

## Projeyi Çalıştırma

1. GitHub üzerinden proje deposunu açın.
2. Depoyu Codespaces ortamında açın.
3. Terminal bölümünü açın.
4. Aşağıdaki komutu çalıştırın:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

5. PORTS sekmesine girin.
6. 8000 numaralı portun yanındaki Open in Browser seçeneğine tıklayın.
7. Açılan sayfadan projeyi görüntüleyin.
